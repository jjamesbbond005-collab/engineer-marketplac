# School Management System

A responsive full-stack school management website built with Next.js, Tailwind CSS, and API routes.

Features:
- Admin dashboard
- Student management
- Teacher overview
- Attendance tracking
- Grade monitoring
- Announcement panel
- Modern UI designed for schools

## Tech Stack
- Next.js 14
- React 18
- TypeScript
- Tailwind CSS

## Local Development

```bash
npm install
npm run dev
```

Then open: http://localhost:3000

## Production Deployment

This project is prepared to deploy on Vercel.

1. Push the code to GitHub.
2. Import the repository into Vercel.
3. Use the default Next.js settings.
4. Deploy.

For production database and authentication, connect a Postgres database such as Supabase or Neon and add the environment variables in Vercel.

## Project Structure

- `app/` – Frontend pages and API routes
- `lib/` – Shared data and business logic
- `public/` – Static assets

## Notes

This version is optimized as a modern demo and starter project for a school management platform. You can extend it with real authentication, a database, payment features, and staff portals.
